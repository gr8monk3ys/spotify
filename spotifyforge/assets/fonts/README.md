# Fonts embedded in the taste page

`export page` inlines these three files into the HTML it writes, so the page
fetches nothing when opened. They are the latin subsets served by Google Fonts,
unmodified, and each is licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which permits redistribution with this notice.

| File | Family | Copyright |
|---|---|---|
| `fraunces-latin.woff2` | Fraunces (variable, 100-900) | The Fraunces Project Authors (https://github.com/undercasetype/Fraunces) |
| `instrument-sans-latin.woff2` | Instrument Sans (variable, 400-700) | The Instrument Sans Project Authors (https://github.com/Instrument/instrument-sans) |
| `ibm-plex-mono-500-latin.woff2` | IBM Plex Mono Medium | IBM Corp. (https://github.com/IBM/plex) |
